Why Clay

Everything an interface needs, nothing it doesn't.

Token-driven to the core

More than 120 CSS custom properties cover colour, shape, type, spacing, density, depth and motion. Change one variable and every component follows. Light, dark and auto modes come built in, and colour ramps are derived for you with color-mix().

Every device

Phone, tablet, desktop, watch and TV breakpoints, with device frames for mockups and safe-area aware bars.

Accessible by default

Native elements, ARIA roles, keyboard navigation, visible focus rings, a contrast checker and reduced-motion support.

Zero dependencies

One CSS file and one optional JS file. Works with plain HTML, React, Vue, Svelte, Angular, Astro, Rails, Laravel and Django.

Native token export

Ship the same theme to SwiftUI, Jetpack Compose, Flutter, WinUI/XAML, GTK, Tailwind, SCSS and Figma (DTCG).

Live theming

Your brand, in seconds.

Drag a slider and watch the whole system respond. Your theme is saved locally, shareable by link and exportable to any platform.

Ship it

Three lines to native.

1Add from CDN

Drop the stylesheet and runtime into any page. No build step.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/clay-ds@1/dist/clay.min.css">
<script src="https://cdn.jsdelivr.net/npm/clay-ds@1/dist/clay.min.js" defer></script>

2Pick a platform

Set it in HTML, or let Clay detect the visitor's OS.

<html data-clay-os="auto" data-clay-mode="auto">
<body class="clay">
  <button class="clay-btn">Continue</button>

3Make it yours

Theme at runtime, or export tokens to native apps.

Clay.init({ os: 'auto', mode: 'auto' });
Clay.setTheme({ primary: '#e11d48', radius: 16 });
Clay.export('swiftui'); // or compose, flutter…
