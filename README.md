# Clay Design System

**One token-driven design system for every screen.** Clay speaks every platform's language: Web, iOS, Android, macOS, Windows and Linux. Pick a platform, tune colour, type, radius, density and motion live, then ship with one CDN line or export native tokens.

- **6 platform presets**: Clay/Web, iOS (HIG), Android (Material 3), macOS (HIG), Windows 11 (Fluent 2) and Linux (GNOME Adwaita)
- **180+ components across six native catalogs**: each platform shows only its own components under their native names (Web 108, iOS 46, Android 57, macOS 55, Windows 64, Linux 51), checked against Ant Design, Material 3, Fluent 2, Apple HIG and GNOME/libadwaita by `npm test`
- **120+ CSS variables**: every decision is a `--clay-*` token, and colour ramps derive automatically
- **Live theming API**: `Clay.setTheme({ primary, radius, font, density, … })`
- **Native export**: CSS, SCSS, JSON, Figma/DTCG, Tailwind, SwiftUI, Jetpack Compose, Flutter, WinUI/XAML, GTK
- **Zero dependencies**: about 37kb gzipped for CSS + JS, and the JS is optional

## Install

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/clay-ds@1/dist/clay.min.css">
<script src="https://cdn.jsdelivr.net/npm/clay-ds@1/dist/clay.min.js" defer></script>
```

```bash
npm install clay-ds
```

```js
import 'clay-ds/dist/clay.css';
import Clay from 'clay-ds';
Clay.init({ os: 'auto', mode: 'auto' });
```

## Use

```html
<html data-clay-os="auto" data-clay-mode="auto">
<body class="clay">
  <button class="clay-btn">Continue</button>
  <input type="checkbox" role="switch" class="clay-switch" checked>
</body>
```

`data-clay-os`: `web | ios | android | macos | windows | linux | auto`. `data-clay-mode`: `light | dark | auto`.

## Theme

```css
:root { --clay-primary: #e11d48; --clay-radius: 16px; --clay-font: "Sora", sans-serif; }
```

```js
Clay.setTheme({ theme: 'ocean', density: 0.9 });
Clay.export('swiftui'); // compose, flutter, xaml, gtk, tailwind, figma, json, scss, css
```

## Project layout

| Path | What |
| --- | --- |
| `dist/clay.css`, `dist/clay.js` | The library (readable source) |
| `dist/clay.min.*`, `dist/tokens.json` | CDN bundle, generated by `npm run build` |
| `tailwind.js` | Tailwind preset (`require('clay-ds/tailwind')`) |
| `index.html`, `components.html`, `foundations.html`, `docs.html` | Documentation site (components page = per-platform catalog + live Foundations panel) |
| `assets/js/catalog/*.js` | Component catalog: one entry per component, tagged with the platforms it belongs to |
| `scripts/coverage.mjs` | Coverage test against each platform's official component inventory |
| `assets/` | Site-only styles and scripts (galaxy, smooth scroll, components workspace) |

## Develop & deploy

```bash
npm install          # esbuild for JS minification
npm run build        # writes dist/clay.min.css, clay.min.js, tokens.json
npm test             # component coverage check (319 platform requirements)
npm run serve        # http://localhost:5180
```

The site is fully static. Push to GitHub and the included workflow deploys it to GitHub Pages, or import the repo into Netlify or Vercel (configs included). Run `npm publish` to put the package on npm, after which jsDelivr and unpkg serve it automatically.
